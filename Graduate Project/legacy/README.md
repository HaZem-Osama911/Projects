# Legacy material

هذا المجلد لا يدخل في التشغيل أو النشر. محتوياته محفوظة فقط للرجوع إليها:

- `php`: تطبيق PHP الأصلي الذي نُقل محتواه إلى Laravel.
- `react-prototype`: قالب React تجريبي غير مستخدم.
- `pronunciation-selector`: واجهة اختيار لغة قديمة وأصول نماذج غير مستخدمة.

مخلفات `obsolete-workspace` وملف تثبيت Python الموجود في النسخة المحلية
مستبعدة من النشر؛ لا يحتاجها التطبيق ولا أداة تحويل الصفحات.

التطبيق الفعلي موجود في `../web` وخدمات النطق في
`../services/pronunciation`.
