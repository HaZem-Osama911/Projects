# 📚 دليل الإرشاد الأكاديمي — توثيق كامل للمشروع

## 📌 نظرة عامة

هذا مشروع **ASP.NET Core 10 Web API** يعمل كـ Backend لنظام إرشاد أكاديمي ذكي.
يقوم الأدمن برفع كشوف الدرجات ولائحة الجامعة، ويقوم نموذج AI بتحليلها وترشيح المواد للطالب.

## ⚙️ إعداد المشروع خطوة بخطوة

### الخطوة 1 — استنساخ المشروع

```bash
# افتح terminal في المجلد الذي تريد حفظ المشروع فيه ثم:
# قم باستخراج المجلد وافتح terminal داخل مجلد الـ G_Project
cd G_Projects\G_Project\G_Project
```

### الخطوة 2 — تثبيت الحزم

```bash
dotnet restore
```

### الخطوة 3 — إعداد قاعدة البيانات

افتح ملف `appsettings.json` وتأكد من صحة connection string:

```json
"ConnectionStrings": {
  "DefaultConnection": "Server=(localdb)\\MSSQLLocalDB;Database=GProjectDB;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=true"
}
```

ثم نفّذ Migration لإنشاء الجداول:

```bash
dotnet ef database update
```

### الخطوة 4 — تشغيل AI Service (Python)

```bash
cd ..\AI
pip install -r requirements.txt
uvicorn tester:app --host 127.0.0.1 --port 8000 --reload
```

أو استخدم `start_ai.bat` مباشرة.

### الخطوة 5 — تشغيل الـ Backend

```bash
dotnet run
```

النظام سيعمل على: `http://localhost:5073`

### الخطوة 6 — فتح Swagger

```
http://localhost:5073/swagger
```

## 🔐 نظام المصادقة (JWT Authentication)

### طريقة الاستخدام

1. سجّل مستخدم وخذ الـ token من الـ Login
2. في كل request يحتاج توثيق، أضف في الـ Header:

```
Authorization: Bearer <YOUR_TOKEN_HERE>
```

### أنواع المستخدمين

| Role      | الوصف                                            |
| --------- | ------------------------------------------------ |
| `Admin`   | يملك صلاحيات رفع الملفات وإدارة المواد وتشغيل AI |
| `Student` | يرى ملفه الشخصي ويسجل المواد المتاحة فقط         |

## 📋 جميع الـ API Endpoints

### 🔑 Auth Endpoints (لا يحتاج توثيق)

#### `POST /api/auth/register` — تسجيل مستخدم جديد

```json
{
  "fullName": "Ahmed Ali",
  "email": "ahmed@example.com",
  "password": "Password@123",
  "role": "Student"
}
```

> `role` يكون `"Admin"` أو `"Student"` (الافتراضي: Student)

**Response:**

```json
{
  "success": true,
  "message": "Registration successful as Student.",
  "data": "User Created Successfully"
}
```

---

#### `POST /api/auth/login` — تسجيل الدخول

```json
{
  "email": "ahmed@example.com",
  "password": "Password@123"
}
```

**Response:**

```json
{
  "success": true,
  "message": "Login Successful",
  "data": "eyJhbGciOiJIUzI1NiIsInR..."
}
```

> احفظ الـ `data` (JWT token) واستخدمه في كل request تالٍ

---

### 👨‍💼 Admin Endpoints `[Authorize: Admin Role]`

#### `POST /api/admin/upload-student-transcript/{studentId}` — رفع كشف درجات طالب

- **Type:** `multipart/form-data`
- **Param (URL):** `studentId` = ID الطالب (string من Identity)
- **Body:** ملف `file` (PDF, PNG, JPG, DOCX — حجم أقصى 10MB)

**Response:**

```json
{
  "success": true,
  "message": "Transcript uploaded successfully.",
  "data": "path/to/file"
}
```

---

#### `POST /api/admin/upload-regulation` — رفع لائحة الجامعة

- **Type:** `multipart/form-data`
- **Body:** ملف `file`
- يُلغي أي لائحة قديمة ويضع هذه كـ active

---

#### `GET /api/admin/courses` — عرض جميع المواد

**Response:**

```json
{
  "data": [
    {
      "id": 1,
      "code": "CS101",
      "name": "مقدمة في البرمجة",
      "creditHours": 3,
      "isOpen": true,
      "prerequisites": []
    }
  ]
}
```

---

#### `POST /api/admin/courses` — إضافة مادة جديدة

```json
{
  "code": "CS201",
  "name": "هياكل البيانات",
  "creditHours": 3,
  "isOpen": true
}
```

---

#### `PUT /api/admin/courses/{id}` — تعديل مادة

```json
{
  "code": "CS201",
  "name": "هياكل البيانات المتقدمة",
  "creditHours": 3,
  "isOpen": false
}
```

---

#### `DELETE /api/admin/courses/{id}` — حذف مادة

---

#### `POST /api/admin/courses/{id}/prerequisites` — إضافة متطلب لمادة

```json
{
  "prerequisiteId": 1
}
```

> يعني مادة `id` تحتاج اجتياز مادة `prerequisiteId` أولاً

---

#### `DELETE /api/admin/courses/{id}/prerequisites/{prereqId}` — حذف متطلب من مادة

---

#### `POST /api/admin/student-completed-course` — تسجيل مادة كمكتملة لطالب

```json
{
  "studentId": "abc123-user-id",
  "courseId": 1
}
```

> يستخدم بعد قراءة كشف الدرجات

### 🤖 AI Endpoints `[Authorize: Admin Role]`

#### `POST /api/ai/analyze/{studentId}` — تشغيل تحليل AI لطالب

- يجلب كشف الدرجات + اللائحة الفعّالة
- يرسلهما لـ Python AI Service
- يحفظ النتيجة في قاعدة البيانات

**Response:**

```json
{
  "success": true,
  "message": "AI analysis complete and result saved.",
  "data": { ... }
}
```

---

#### `GET /api/ai/result/{studentId}` — جلب آخر نتيجة AI لطالب

---

### 🎓 Student Endpoints `[Authorize: أي مستخدم مسجل]`

#### `GET /api/student/my-profile` — ملف الطالب الشخصي

**Response:**

```json
{
  "data": {
    "studentId": "abc123",
    "fullName": "Ahmed Ali",
    "email": "ahmed@example.com",
    "transcript": {
      "id": 1,
      "filePath": "filename.pdf",
      "uploadDate": "2026-04-17T20:00:00Z"
    },
    "latestAiResult": "{\"recommended\": [\"CS301\", \"CS401\"]}",
    "selectedCourses": []
  }
}
```

---

#### `GET /api/student/available-courses` — المواد المتاحة للتسجيل

> فقط المواد المفتوحة (`isOpen=true`) التي اجتاز الطالب **جميع** متطلباتها السابقة
> المواد المقفولة أو غير المستوفاة **لا تظهر نهائياً**

**Response:**

```json
{
  "data": [
    {
      "id": 3,
      "code": "CS301",
      "name": "قواعد البيانات",
      "creditHours": 3,
      "isOpen": true,
      "prerequisites": []
    }
  ]
}
```

---

#### `POST /api/student/select-course/{courseId}` — تسجيل مادة

> يتحقق تلقائياً من:
>
> - المادة مفتوحة
> - لم يُسجّلها من قبل
> - لم يُكملها من قبل
> - جميع المتطلبات مستوفاة

**Response:**

```json
{
  "success": true,
  "message": "Successfully registered for 'قواعد البيانات'.",
  "data": "قواعد البيانات"
}
```

---

#### `GET /api/student/my-selections` — المواد التي سجّلها الطالب

## 🗄️ هيكل قاعدة البيانات

```
AspNetUsers          → جدول المستخدمين (Identity)
AspNetRoles          → الأدوار (Admin, Student)
AspNetUserRoles      → ربط المستخدم بالدور

StudentTranscripts   → كشوف الدرجات (يرفعها الأدمن)
SystemRegulations    → لائحة الجامعة (الأدمن)
AiAnalysisResults    → نتائج الـ AI

Courses              → جدول المواد
CoursePrerequisites  → المتطلبات السابقة (self-join)
StudentCompletedCourses → المواد المنهية للطالب
StudentCourseSelections → تسجيل الطالب للمواد
```

## ⚠️ ملاحظات مهمة للفريق

1. **JWT Token صلاحيته 60 دقيقة** — بعدها يجب تسجيل الدخول من جديد
2. **ملفات الـ Uploads** محفوظة على السيرفر في مجلد `Uploads/` — لا تُعرض المسار الكامل للعميل
3. **CORS مفتوح لجميع الـ Origins** — يمكن تعديله في `Program.cs` للـ Production
4. **AI Service** يجب أن يكون شغالاً على `http://127.0.0.1:8000` قبل استدعاء `/api/ai/analyze`
5. **أنواع الملفات المسموحة:** `.jpg .png .pdf .txt .csv .json .docx`
6. **حجم الملف الأقصى:** 10 MB

## 🚨 رسائل الخطأ الشائعة

| كود                | السبب                                                               | الحل                                              |
| ------------------ | ------------------------------------------------------------------- | ------------------------------------------------- |
| `401 Unauthorized` | لم يتم إرسال JWT Token                                              | أضف `Authorization: Bearer <token>` في الـ Header |
| `403 Forbidden`    | المستخدم لا يملك الصلاحية (مثلاً Student يحاول وصول Admin endpoint) | تأكد من الـ Role                                  |
| `400 Bad Request`  | بيانات ناقصة أو غير صحيحة                                           | راجع الـ `errors` في الـ Response                 |
| `404 Not Found`    | العنصر غير موجود في قاعدة البيانات                                  | تحقق من الـ ID                                    |
| `409 Conflict`     | العنصر موجود بالفعل (تكرار)                                         | لا تُضف نفس الشيء مرتين                           |

## 🔄 سيناريو استخدام كامل (Flow)

```
1. Admin يسجّل دخول → يحصل Token
2. Admin يرفع لائحة الجامعة → POST /api/admin/upload-regulation
3. Admin يرفع كشف الطالب → POST /api/admin/upload-student-transcript/{studentId}
4. Admin يضيف المواد → POST /api/admin/courses
5. Admin يضيف المتطلبات → POST /api/admin/courses/{id}/prerequisites
6. Admin يُسجّل المواد المنهية للطالب → POST /api/admin/student-completed-course
7. Admin يشغّل AI → POST /api/ai/analyze/{studentId}
8. Student يسجّل دخول → يحصل Token
9. Student يرى ملفه → GET /api/student/my-profile
10. Student يرى المواد المتاحة → GET /api/student/available-courses
11. Student يسجّل مادة → POST /api/student/select-course/{courseId}
```
